# The Plug Barbershop Website

A modern and stylish barbershop website built with **React** and **Vite**.
The goal of this project was to create a premium-looking landing page for a fictional barbershop brand called **The Plug**.

## About the Project

This website was designed to feel bold, cinematic, and professional. Instead of creating a basic barbershop layout, I focused on a luxury visual style with strong typography, dark backgrounds, warm brown/orange accents, large images, and small interactive details.

The website includes multiple sections that guide the user through the brand, services, gallery, booking information, location details, and social links.

## Features

* Modern responsive landing page
* Hero section with large typography
* Animated moving text bar
* Services section with prices
* Gallery with hover effects
* Booking call-to-action section
* Location and opening hours section
* Footer with social media links
* Component-based React structure

## Design Style

The design uses a dark premium style with a warm accent color.

Main colors:

```text
Background: #080808
Section dark: #11100d
Light section: #e9e6df
Accent: #b87532
Text: #f4efe8
```

The typography is mostly uppercase and bold to create a strong barbershop identity.

## What I Learned

During this project, I practiced building a full website using React components. I also improved my CSS skills by working with Flexbox, CSS Grid, hover effects, image positioning, spacing, and responsive layouts.

One of the main challenges was recreating the design accurately in code. Small details such as line-height, image size, alignment, and spacing made a big difference in the final result.
